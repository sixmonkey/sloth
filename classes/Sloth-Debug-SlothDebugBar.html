SlothDebugBar extends DebugBar
in package
  • Application

SlothDebugBar.php : 25

Extended PHP DebugBar for the Sloth framework.

Wraps the base DebugBar with core collectors (time, messages, exceptions) and provides a boot() method that loads custom collector providers from the debugger configuration.

boot()

SlothDebugBar.php : 87

Boot the DebugBar by loading all registered collector providers.

public boot() : void

Each provider from debugger.bar.collector_providers is instantiated with this DebugBar instance and booted, which adds its collectors (queries, sloth, acf, wordpress, etc.).

Idempotent — calling boot() multiple times is safe.
